# MultiComs · 국립공주대학교 멀티미디어통신연구실

**홈페이지: https://universitymaker.github.io**

멀티미디어통신연구실(MultiComs)은 볼류메트릭·포인트 클라우드 영상과 촉각을 포함한 다중감각 미디어를 사용자에게 실시간으로 전달하는 통신 기술을 연구합니다. 주요 연구 분야는 다음과 같습니다.

- 볼류메트릭·포인트 클라우드 스트리밍
- 촉각·다중감각 미디어
- 저지연·고신뢰 네트워크
- 실감 방송·OTT 전송

지도교수: 유동호 (국립공주대학교 컴퓨터교육과) · dongho.you@kongju.ac.kr

---

The Multimedia Communications Laboratory (MultiComs) at Kongju National University studies how immersive media can be delivered faster and more realistically. Our work covers volumetric and point cloud streaming, haptic and multisensory media, low-latency and reliable networking, and immersive broadcast and OTT delivery.
